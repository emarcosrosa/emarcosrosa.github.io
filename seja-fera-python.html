Visão geral do livro

Uma introdução aos fundamentos da programação com Python, pensada para tornar o aprendizado mais claro e acessível.

Aprender programação não precisa ser complicado.

Seja Fera em Python foi desenvolvido para quem deseja dar os primeiros passos na programação de forma prática, organizada e objetiva.

Utilizando uma linguagem clara e exemplos do cotidiano, o livro apresenta os fundamentos da linguagem Python, uma das tecnologias mais utilizadas no mundo em áreas como desenvolvimento de software, ciência de dados, automação, inteligência artificial e computação em nuvem.

Ao longo dos capítulos, o leitor aprenderá os principais conceitos da programação, desde a instalação do ambiente até a criação de programas completos utilizando estruturas de decisão, repetição, funções, coleções de dados e manipulação de arquivos.

Cada capítulo apresenta exemplos comentados, exercícios propostos, desafios e boas práticas de programação para consolidar o aprendizado. 
def aprender_python():
    linguagem = "Python"
    objetivo = "aprender programação"

    return (
        linguagem,
        objetivo
    )

print(aprender_python())
